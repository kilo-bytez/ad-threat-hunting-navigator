# AD Threat Hunting Navigator

A complete static, interactive Windows/Active Directory hunting guide for Splunk.

Open index.html or the GitHub Pages site. Includes guided hunts, SPL searches, event/field reference, hypothetical attack paths, vulnerability review, local XML/CSV interpretation, case notes and exports.

No backend or Splunk connection. Case data stays in browser storage and is not shared between users or devices. Export workspace JSON for a portable backup. File and HTTPS origins have separate storage. Raw imported CSV/XML is not uploaded. No analytics or external script dependencies.

SPL templates require local validation. The dated CVE snapshot does not update itself; verify current advisories and asset applicability. Hypothetical scenarios are not evidence.

Source snapshot: 2026-10-15, Navigator 5.2.
